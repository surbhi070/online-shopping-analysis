# Online Shopping Analysis

## 📊 Project Overview
This project analyzes and optimizes online shopping behavior by studying key customer and revenue metrics through interactive dashboards.

**Objective:**  
To deliver actionable insights into customer behavior, revenue streams, and marketing effectiveness.

## 🛠 Tools Used
- Excel (Dashboard creation and visualization)

📈 Key Metrics Analyzed
- Customer Lifetime Value (CLV)
- Coupon Usage Rate
- Churn Rate
- Average Order Value (AOV)
- Product Category Performance
- Gender-Based Revenue Analysis
- Regional Performance (Heat Maps)

✅ metric explanation
 📊 KPIs Defined
- CLV = Avg Order Value × Purchase Frequency × Customer Lifespan
- Churn Rate = Lost Customers / Total Customers
- AOV = Total Revenue / Number of Orders

✅ Insights 
- High coupon usage does not always translate to higher retention
- Female customers contribute higher revenue in certain categories
- Certain regions show high traffic but low conversion

  
✅ Recommendations
- Optimize coupon strategies to improve profitability
- Target high-value customer segments
- Improve conversion rates in underperforming regions

  “Translated analytical findings into actionable business recommendations.”
