# Online Shopping Analysis

## 📊 Project Overview
This project analyzes and optimizes online shopping behavior by studying key customer and revenue metrics through interactive dashboards.

**Objective:**  
To deliver actionable insights into customer behavior, revenue streams, and marketing effectiveness.

## 🛠 Tools Used
- Excel (Dashboard creation and visualization)

## 📈 Key Metrics Analyzed
- Customer Lifetime Value (CLV)
- Coupon Usage Rate
- Churn Rate
- Average Order Value (AOV)
- Product Category Performance
- Gender-Based Revenue Analysis
- Regional Performance (Heat Maps)

## 📂 Project Files
- **Online Shopping proj.pptx** – Presentation containing full dashboard visualizations and insights.

## 🔮 Future Scope
- Deep-dive customer segmentation.
- Predictive analytics for targeted marketing.
